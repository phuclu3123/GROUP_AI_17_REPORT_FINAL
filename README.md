# GROUP_AI_17_REPORT_FINAL

## Đồ án Trí Tuệ Nhân Tạo (Artificial Intelligence Project)

* **ĐỀ TÀI:** Giải bài toán tối ưu Mạng/Luồng giao thông (Network Flow Problem) dựa vào giải thuật GA.
* **BÀI TOÁN:** Ứng dụng giải thuật di truyền (Genetic Algorithm) vào bài toán định tuyến phương tiện (VRP - Vehicle Routing Problem).

---

## 📖 Giới thiệu (Introduction)
Dự án này ứng dụng Giải thuật Di truyền (Genetic Algorithm - GA) để giải quyết và tìm ra giải pháp tối ưu cho bài toán định tuyến phương tiện (VRP). Hệ thống cung cấp một giao diện trực quan để người dùng thiết lập tham số, chạy thuật toán và quan sát kết quả đường đi được vẽ trực tiếp trên bản đồ.

## ✨ Tính năng chính (Features)
* **Tối ưu hóa bằng GA:** Cài đặt thuật toán di truyền với các phép lai ghép và đột biến để tìm kiếm lộ trình tốt nhất.
* **Giao diện Desktop:** Ứng dụng xây dựng trên PyQt6 giúp thao tác mượt mà và thân thiện.
* **Trực quan hóa bản đồ:** Kết hợp Folium để xuất html/vẽ bản đồ tương tác hiển thị các điểm giao hàng và lộ trình di chuyển.
* **Tùy chỉnh tham số:** Dễ dàng thay đổi các cấu hình đầu vào của GA (kích thước quần thể, số thế hệ, tỷ lệ đột biến...).

## 🛠 Yêu cầu hệ thống (Prerequisites)
Đảm bảo máy tính của bạn đã cài đặt sẵn:
* **Python** (phiên bản 3.8 trở lên)
* **PyQt6** (phiên bản 6.5.0 trở lên)
* **Folium** (phiên bản 0.12.0 trở lên)

## 🚀 Cài đặt (Installation)

**1. Clone repository về máy:**
Mở terminal và chạy lệnh sau:
```bash
git clone 
cd AI-Project-GA-Algorithm-VRP
```
**2: Cài đặt thư viện**
Bạn cần cài đặt các thư viện sau:
- Python (phiên bản 3.8 trở lên)
- PyQt6 (phiên bản 6.5.0 trở lên)
- Folium (phiên bản 0.12.0 trở lên)

Mở terminal và chạy lệnh sau:
```bash
$ pip install -r requirements.txt
```
